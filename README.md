#  Intermittent Fasting Tracker

A simple web application to track fasting time, monitor water intake, and stay consistent with intermittent fasting routines.

---

##  Features

*  Fasting Timer (real-time countdown)
*  Water Intake Tracker
*  Dark / Light Mode Toggle
*  Motivational Tips Rotation
*  Responsive UI Design

---

##  Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)

---

##  How It Works

### Fasting Timer

* Select a fasting plan (16:8, 18:6, etc.)
* Timer starts counting down in real-time
* Status updates dynamically

### Water Tracker

* Enter water intake in ml
* Total water consumption updates instantly

### Dark Mode

* Toggle between light and dark themes
* Improves usability for different environments

### Motivational Tips

* Random tips displayed every few seconds
* Keeps users engaged and consistent
